- **角色是嚴肅的。** 主角與搭檔的個性、造型比照里昂、克萊兒那種認真的生存恐怖主角；主角**不覺得自己是帥哥**，也沒有任何「帥」的梗或機制

## 1. 定位：讓玩家說「這是另類的惡靈古堡」，而不是「又一款恐怖遊戲」

只做「恐怖＋幽默」，玩家會把它歸類成一般的恐怖喜劇。要讓人一看就想到惡靈古堡，靠的是兩件事：

1. **玩家身體記得的「儀式」全部保留**：固定視角、開門動畫、打字機存檔、互通的道具箱、徽章開門、文件檔案、追擊者、自爆倒數、最後丟火箭筒給你。這些是**玩法與結構**，不受著作權保護
2. **幽默的對象是這些儀式本身**，而且是透過事件和文字：吐槽「為什麼一棟房子要四枚獎章才能開門」、道具箱為什麼會互通。只有玩過惡靈古堡的人才會懂，這就是「另類惡靈古堡」的辨識度

主角們**完全認真地**面對這一切；荒謬感來自世界，不來自角色。就像一部正經拍攝的 B 級恐怖片，演員沒有在搞笑，但情節本身很好笑。

UnMetal 拿的是**敘事手法**：主角事後向別人講述事件，聽的人會吐槽。本作的版本是「寫給內務組的事故報告」（見第 3 節），不使用 UnMetal 的角色、台詞與審訊設定。

### 版權與專利的紅線

- **不用**：Resident Evil／Biohazard／惡靈古堡、Umbrella、浣熊市、S.T.A.R.S.、RPD、T 病毒、Tyrant、里昂／克萊兒／吉兒等名稱；原作台詞（包含知名的爛台詞）；原作地圖配置與謎題細節
- **造型「貼近」但不複製**（見第 4 節的造型表）：
  - 男主角：可以是菜鳥警察的裝備（制服、戰術背心、腰帶、大腿槍套），這是寫實職業服裝。**不用**里昂的金色中分瀏海、RPD 字樣與標誌、RE2 制服的配色
  - 女主角：可以是騎士皮夾克、牛仔褲、靴子，這是常見的服裝。**不用**克萊兒的「紅色皮夾克＋馬尾＋短褲」組合、背後的字樣與圖案
  - 怪物：**不用** Mr. X 與 Nemesis 的風衣與帽子，原作的殭屍、舔食者、獵人等造型
- **具體謎題避開**：月光奏鳴曲鋼琴、太陽／月亮／星星／風四枚徽章、天花板下降的獵槍陷阱、綠紅藍三色藥草組合
- **紅十字標誌**受國際法保護，醫療道具不使用紅色十字
- **直銷公司是虛構的**，不影射任何真實公司。諷刺的對象是「機制」和創辦人，**不嘲笑一般經銷商**（見第 8 節）
- **專利**：1996–1999 年代相關技術的專利都已超過 20 年；開工前再針對個別系統查一次
- 這是開發上的避險原則，不是法律意見；若要商業發行再請律師確認

## 2. 故事一句話

1998 年秋天的暴風雨夜，菜鳥副警長柯爾上班第一天，被派去處理一通「宴會太吵」的報案。地點是長青生命創辦人的莊園，年度「鑽石之夜」上，頂級經銷商們喝下了新配方的永春露。同一晚，快遞員諾拉為了找失蹤的姊姊，也闖進了這座莊園。

---

## 3. 敘事框架：事故報告

- **現在**：隔天早上 8 點，郡警局的小會議室。內務組的**桃樂絲・柯恩警佐**逐頁審閱柯爾的事故報告。她不相信有殭屍，只關心報告格式和公款
- **遊戲本體＝報告的內容**。每章開頭和關鍵時刻切回會議室
- **打字機存檔就是柯爾在寫報告**：存檔畫面是報告紙一行一行打出來，用的是警察報告的公文語氣（例：「22:47，本人於餐廳遭遇行為異常之民眾三名，已依程序警告，對方未停止。」）。**笑點是公文語氣和實際狀況的落差**，柯爾本人寫得非常認真
- **報告的選擇**（UnMetal 式手法，原創內容）：桃樂絲問「然後呢？」時，玩家選擇報告怎麼寫。選擇會改變小事：拿到的道具、一段捷徑、桃樂絲的反應，不影響主線
  - 例：桃樂絲問門是怎麼打開的。「用撬棍破壞」→「那是私人財產，要另外寫損壞報告。」（多一份文件，裡面有線索）；「門沒鎖」→ 桃樂絲記下「門沒鎖」，之後的對話會一直被提起
- **結尾是報告的結論**：依存檔次數、時間、選擇，桃樂絲寫下不同的評語（見第 9 節）

## 4. 角色

角色全部是認真的。笑點來自他們**認真面對荒謬的處境**（deadpan），不是他們自己搞笑。

| 角色 | 定位 | 個性 |
|---|---|---|
| **柯爾・哈特利** | 主角，24 歲，松脊郡警局菜鳥副警長，上班第一天 | 認真、守規矩、有正義感、話不多。第一天就遇上這種事，但他選擇把該做的事做完：救人、記錄、離開。和里昂一樣，是「被丟進地獄的普通好人」 |
| **諾拉・維加** | 女主角，26 歲，機車快遞員 | 冷靜、行動派、嘴硬心軟。姊姊**艾琳**是長青生命的會計，三週前寄了一個包裹給她，之後就失聯了。包裹裡是一本帳本的一部分 |
| **艾琳・維加** | 諾拉的姊姊，長青生命會計部，內部吹哨者 | 不出場（或最後才出場）。她的筆記散落在莊園各處，是主線線索 |
| **奧古斯特・哈洛威** | 創辦人，最終頭目 | 自稱 70 歲、看起來 40 歲。莊園到處都是他的勵志錄音帶 |
| **昆廷・奎爾** | 莊園的建築師（推定已死） | 熱愛謎題。他的留言是吐槽「謎題洋館」這個類型的主要管道 |
| **上線** | 追擊者 | 前保鑣，最高階的「皇冠大使」。打不死，只能擊倒一陣子 |
| **桃樂絲・柯恩** | 內務組警佐，框架敘事的聽眾 | 一板一眼，是笑點的主要來源（她用處理交通事故的態度處理殭屍事件） |
| **郡警長**（只有無線電） | 柯爾的長官 | 每次呼叫都在講別的事 |

### 造型（取代 v1 的設定稿，v1 的卡通角色作廢）

| 角色 | 造型方向 | 和原作的差異 |
|---|---|---|

殭屍的設計原則：**外觀是恐怖的**，帶有一點「生前身分」的線索（名牌、制服、獎牌），讓玩家知道他們是誰。黑色幽默放在**情境**裡（例如殭屍手上還捏著產品傳單、人體金字塔的形狀），不放在角色表情或可愛的造型上。

**合計約 46 個房間、約 120 個機位、第一次遊玩約 3 小時 55 分。**
時間的組成：探索與戰鬥約 50%、解謎約 30%、來回走動與存檔約 20%。

### 地圖結構原則

- **中心是前廳的「榮譽之牆」**：四枚獎章全部到手才能打開最後的門
- 每章都會開一條**回到前廳的捷徑**，讓回頭的路越走越短
- 安全房 4 間：一樓、東翼、溫室旁的工具間、研究所。每間都有打字機、物流箱、安全房音樂

### 艾琳的故事線（主線的情感核心）

- 第 1 章：諾拉手上的帳本只有一半；艾琳的識別證掉在升降機裡
- 第 2–3 章：艾琳的筆記，記錄她發現帳本裡「經銷商存活率」這個欄位
- 第 4 章：研究所的病患名單上有艾琳的名字
- 結局分歧：是否能在第 4 章找到她（見第 9 節）

### 謎題的原則

- 線索都在同一章裡（P10 例外：刻意設計成柯爾與諾拉要合作）
- 每個謎題都可以從場景或文件推理出來，不需要猜；奎爾的留言提供一點提示
- 謎題種類輪流出現：觀察、推理、操作、道具使用、文件對照
- 只用手把就能玩，不做大量文字輸入的謎題

## 10. 幽默原則

- **恐怖是真的。** 戰鬥、資源緊張、jump scare 照原作的標準做，笑點不拿來稀釋緊張感
- **角色是認真的。** 柯爾、諾拉、艾琳都不搞笑；笑點來自他們認真面對荒謬的處境
- **笑點放在**：檢查描述、文件、奎爾的留言、桃樂絲的吐槽、系統訊息、公文語氣的報告、勵志錄音
- **緊張的時候不搞笑**：追擊者出現、頭目戰期間沒有笑點
- **嘲笑機制，不嘲笑受害者**（見第 8 節）

## 10.5 絕命毒師的彩蛋（2026-10-19）

可以加，但**當彩蛋，不當主菜**。原則：

- **用暗示，不用引用。** 不用角色名字、原台詞（包括最有名的那句「敲門」的台詞）、角色造型（帽子＋墨鏡的剪影）、劇照構圖。看過的人會心一笑，沒看過的人也不會覺得奇怪
- **數量少：全遊戲 4–5 個。** 太多會蓋過「另類惡靈古堡」的定位
- **要能自然地放進這個世界。** 長青生命本來就是一間在莊園地下偷偷做「產品」的公司，和絕命毒師的設定剛好呼應

| 彩蛋 | 放在哪裡 | 看過的人會想到 |
|---|---|---|
| 研究所的入口藏在**洗衣房**的機器後面 | 第 4 章的入口 | 洗衣房底下的超級實驗室 |
| 研究所的品管報告：「本批永春露純度 99.1%，首席化學家拒絕出貨，要求重做到 99% 以上的『那個數字』」 | 第 4 章文件 | 純度執念 |
| 泳池抽乾後，池底有一隻**少了一隻眼睛的粉紅色泰迪熊** | 第 2 章 P7 | 漂在泳池裡的熊（我們自己設計外型） |
| 屋頂上有一個**被丟上來的披薩盒** | 第 5 章屋頂 | 丟上屋頂的披薩 |
| 首席化學家的履歷：「前高中化學老師」 | 第 4 章文件 | 化學老師的轉職 |
| 上線（追擊者）**敲門** | 第 2 章起 | 敲門這個動作本身就是梗，不需要台詞 |

## 10.6 品質目標：做到「有人催續作」

目標不是一個給其他創作者參考的範例，而是一款**本身就值得玩、玩完會想要下一集**的遊戲。具體要做到：

### 玩完會記得的東西

| 項目 | 做法 |
|---|---|
| **一個有辨識度的世界觀** | 「直銷公司版的生化危機」一句話就講得完，而且別人沒做過 |
| **會被截圖分享的場面** | 第一隻殭屍轉頭、人體金字塔、自爆倒數的勵志廣播、熱氣球逃生。每章至少一個 |
| **安全房音樂** | 原創、有記憶點；這類遊戲最讓人懷念的就是存檔房的音樂（Neil 作曲） |
| **角色有弧線** | 柯爾從「處理噪音投訴的菜鳥」變成「決定要把事情做完的人」；諾拉從找姊姊到接受結果 |
| **桃樂絲的最後一句話** | 每個結局都有一句會被引用的結語 |

### 續作的伏筆

- **長青生命只是一個下線。** 最後一份文件（破關後才拿得到）：創辦人的「上線」名單，上面還有一層更大的公司。哈洛威自己也是被拉進來的
- **桃樂絲的結語**（好結局）：「報告收到。另外，柯爾，下週一開始你調到我這裡，還有其他報告要寫。」→ 續作的主角組合
- 主選單的「讀取報告」在破關後多一個灰色的欄位：「事故報告 #2　未歸檔」

### 打磨的標準（每個房間都要過）

- 每個可以檢查的東西都有自己的描述，不能出現「這裡什麼都沒有」
- 開門、上樓、拿道具都有音效；腳步聲依地板材質不同
- 每個機位都要有「為什麼放在這裡」的理由：製造緊張、藏住轉角、展示新區域
- 殭屍第一次出現的位置都要經過設計（從畫面外走進來、背對玩家、躺在地上突然起身）
- 第一次遊玩卡關超過 10 分鐘的地方，要加提示或改設計

### 發布與試玩

- **先做 30 分鐘的試玩版**（序章＋第 1 章前半），放在網頁上，玩家點開就能玩
- 找 5–10 位沒看過企劃的人試玩，觀察他們卡在哪裡、在哪裡笑、在哪裡被嚇到（不給提示，只看）
- 試玩版的結尾停在一個懸念上（例如諾拉從送餐升降機裡拿槍指著柯爾）
- 完整版發布在 Nova 商城與網頁版，同時放 itch.io 擴大觸及

### 最重要的規則：原始素材不進公開 repo

- 原始的 3D 模型、貼圖、音效原檔**只放在本機**（例如 `~/projects/nova/assets/`，加進 `.gitignore`）
- 遊戲 repo 裡只放**渲染後的成品**（背景圖、sprite、轉換過的音效），這屬於「用在作品裡」，各授權都允許
- 維護一份 `CREDITS.md`，列出每個素材的作者、連結、授權，需要署名的照規定寫上

## 13. 引擎（Comet）因此要補的

| 功能 | 原因 |
|---|---|
| 全螢幕背景從 SD 卡串流（換房間時載入） | 120 張背景約 9 MB，不能全放記憶體；**開門動畫正好拿來掩蓋讀取時間** |
| 卡匣支援資源包（或壓縮的二進位區塊） | 「遊戲是單一文字檔」裝不下 9 MB 的背景（要討論是否修改 01 的規則） |
| 每張背景各自的 256 色調色盤 | 預渲染背景需要的顏色比共用調色盤多 |
| 縮放 sprite（依深度） | 角色走遠會變小 |
| 前景遮罩 | 角色走到家具後面會被擋住 |
| 多邊形可走區域＋鏡頭觸發區 | 固定視角的移動與換鏡頭 |
| 存檔 API | 打字機存檔（Wildkin 也需要，見 07 第 9 節） |
| 音效取樣播放 | 腳步聲、開門聲、環境音循環 |
| 坦克式操作的範例 | 放在 AI_GUIDE，方便其他人做同類遊戲 |

另外需要一條**預渲染流程**（Blender 腳本）：擺好場景與攝影機 → 渲染背景、前景遮罩、可走區域 → 量化成 256 色；角色模型 → 8 個方向 × 每個動作 → sprite。這條流程也可以開放給其他創作者使用。
