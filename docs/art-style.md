# 美術規格

最後更新：2026-10-19

## 風格一句話

**1998 年 PlayStation 上的生存恐怖遊戲**：低多邊形、低解析度貼圖、昏暗的寫實光影。角色與怪物是嚴肅、寫實的；幽默只出現在事件與文字裡。

參考方向：itch.io 上的 PSX 恐怖素材（見 CREDITS.md）。只參考風格，所有素材自己做。

## 畫面規格（Level 1）

| 項目 | 規格 |
|---|---|
| 畫面 | 320×240 |
| 背景 | 每個機位一張，**256 色索引**，每張有自己的調色盤 |
| 角色 sprite | 透明色 1 個 + 和背景共用調色盤的顏色（引擎決定合併方式） |
| 前景遮罩 | 每個機位一張深度圖：只有「會擋住角色」的物件有值 |

## 貼圖

| 項目 | 規格 |
|---|---|
| 尺寸 | 牆、地板 128×128；道具 64×64；小東西 32×32 |
| 每張的顏色數 | 16–32 色（量化過），保留 PSX 的色階感 |
| 取樣 | 最近鄰（不平滑），渲染時看得到像素 |
| 世界尺寸 | 牆與地板：一張貼圖 = 2 公尺 |
| 舊化 | 每種材質至少有髒污、水漬、磨損的變化 |

## 模型

| 項目 | 規格 |
|---|---|
| 單位 | 1 = 1 公尺；角色身高 1.75–1.85 m |
| 面數 | 道具 12–300 面；角色 600–1200 面 |
| 建模 | 一律用 `tools/kit.py` 的程式產生，方便 AI 修改與重做 |
| 硬邊 | 平面著色（flat shading）為主 |

## 燈光與渲染

- 渲染器：Cycles（CPU），渲染尺寸 = 320×240，最後量化成 256 色
- 主光源一定要有**理由**：窗外月光、檯燈、燭火、壁爐、走廊壁燈
- 暗部不要純黑：留一點環境光，讓玩家看得到可以走的路
- 色調：
  - 主館：暖色燭光 vs. 冷色月光
  - 研究所：日光燈的冷綠
  - 安全房：比其他房間亮、偏暖，讓玩家一進來就知道安全

## 檔名

- 貼圖：`art/textures/<材質>_<變化>.png`，例：`wallpaper_damask_green.png`
- 房間輸出：`build/rooms/<房間>/<機位>_bg.png`、`<機位>_depth.png`、`room.json`
